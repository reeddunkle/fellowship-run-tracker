## Analytics graph goals

* Layer roles: Classify and visually distinguish implementation layers, composed service bundles, dependency-closing wrappers, and application/runtime composition layers.
* Cross-boundary services: Detect services that participate across several subsystem or composition boundaries.
* Pass-through layers: Detect layers that primarily route or forward existing services without materially changing the provided service contract.
* ~~Service memberships: Detect repeated service membership across composed service bundles and visualize/report the memberships.~~
* ~~Bundle relationships: Detect relationships between service bundles, including equality, strict subsets/supersets, overlaps, and dependency-closing relationships.~~
* ~~Requirement reductions: Detect layers that preserve the same provided services while reducing or fully closing their requirements.~~
